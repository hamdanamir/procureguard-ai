# ProcureGuard AI — Supabase Database

This directory contains the database layer for the ProcureGuard AI procurement automation system.

The database is built with PostgreSQL and Supabase and supports:

- Multi-organization procurement data
- Suppliers and products
- Supplier-product agreements
- Purchase orders and purchase order items
- Invoice and invoice-item processing
- Price history
- Procurement anomaly detection
- Human approval workflows
- Supplier dispute management
- Audit logging
- Processing error tracking
- Organization-specific report configuration
- System-level configuration
- Row Level Security (RLS)

## Security

Production credentials, database passwords, API keys, connection strings, organization-specific private data, and other secrets are not included in this repository.

Database migrations included in this project are intended to document and reproduce the database architecture without exposing production credentials.
